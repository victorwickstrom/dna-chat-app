### Task 2: Initialize npm and create package.json.

1. Run the following command to initialize an NPM package in the project root. Use `-y` to accept the defaults:
   ```bash
   npm init -y
   ```
2. Open the generated `package.json` file and ensure it has a `name` relevant to your project, such as `"name": "dna-chat-app"`. Optionally add a `description` and `repository` field.
3. Leave `main` and `scripts` as the default for now; they will be configured in later tasks.
