### Task 16: Implement vendor detection for DNA files.

1. Create `src/utils/vendor.ts`. Export a function `detectVendor(lines: string[]): 'myheritage' | '23andme' | 'ancestry' | 'unknown'` that inspects the first few lines of the raw file.
2. Implement heuristics:
   - If a line starts with `#Uploaded From MyHeritage` or `MyHeritage`, return `'myheritage'`.
   - If a line starts with `# This data file generated by 23andMe`, return `'23andme'`.
   - If the file contains `# AncestryDNA Raw Data` or similar, return `'ancestry'`.
   - Default to `'unknown'` if none match.
3. Use this function in your worker (Task 19) to decide which parser to invoke.
