### Task 100: Run final tests and release.

1. Execute the full test suite: `npm test`. Confirm all tests pass.
2. Lint and format your code to ensure consistency: `npm run lint` and `npm run format`.
3. Build the production bundle with `npm run build` and preview it with `npm run preview`.
4. Ensure environment variables are set appropriately in your `.env.local` for testing the production bundle.
5. When everything passes and looks correct, update the version number in `package.json` and commit your changes with a message like `chore: complete privacy-first DNA chat assistant`.
6. Push your code to your repository and create a release tag if desired.
