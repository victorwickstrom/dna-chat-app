### Task 1: Initialize project root and git repository.

1. Create a new directory for your project, for example `dna-chat-app`, and navigate into it:
   ```bash
   mkdir dna-chat-app
   cd dna-chat-app
   ```
2. Initialize a new git repository inside the project folder:
   ```bash
   git init
   ```
3. Create a `.gitignore` file that at least ignores `node_modules/`, `.env*`, and build artifacts like `dist/` to prevent committing large or sensitive files. You can use a standard Node.js `.gitignore` template.
