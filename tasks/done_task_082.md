### Task 82: Write comprehensive README documentation.

1. Create a `README.md` in the project root. The README should include:
   - A brief description of the project: what it does, its privacy-first architecture, and how users interact with it.
   - Installation instructions: prerequisites (Node.js version), cloning the repo, installing dependencies with `npm ci`.
   - Running the development server (`npm run dev`), building for production (`npm run build`), and serving the build (`npm run preview`).
   - Running tests (`npm test`) and explaining the CI workflow.
   - Links to the manual (manual.md) and further documentation in the `docs/` directory.
   - Information on environment variables required (Planner/Interpreter endpoints) and how to obtain them.
2. Use Markdown headings and bullet points to organize the sections for readability.
