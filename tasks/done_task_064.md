### Task 64: Create a settings page consolidating preferences and controls.

1. Create `src/pages/Settings.tsx`. This page should include:
   - The `Preferences` component (Task 51) for adjusting user preferences.
   - The `MemoryOverview` component (Task 54) to view memory data.
   - Buttons for `Reset Memory` (Task 56), `Export Memory`, and `Import Memory` (Task 57).
   - A link to the Privacy page (Task 63).
2. Use a simple layout with tabs or headings dividing sections.
3. Make sure that changes in preferences are reflected immediately in the app's behaviour (e.g., language switch).
4. Include a back button or link to return to the main chat screen.
