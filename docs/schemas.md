# JSON Schemas and API Responses

## QueryPlan

The `QueryPlan` is the output from the Planner LLM. It specifies which SNPs to look up and context for the interpretation.

### Schema

| Field          | Type         | Description                                                                 |
| -------------- | ------------ | --------------------------------------------------------------------------- |
| `version`      | `string`     | Schema version (e.g., "1.0")                                                |
| `intent`       | `string`     | The detected intent of the query (e.g., "explore_gene", "compare_variants") |
| `topic`        | `string`     | Main topic category (e.g., "inflammation", "metabolism")                    |
| `snps`         | `SNPEntry[]` | Array of SNPs to look up                                                    |
| `includeNotes` | `string[]`   | Special notes for the interpreter                                           |
| `safety`       | `SafetyInfo` | Safety classification                                                       |

### SNPEntry

| Field      | Type                               | Description                            |
| ---------- | ---------------------------------- | -------------------------------------- |
| `rsid`     | `string`                           | The SNP identifier (e.g., "rs1800795") |
| `gene`     | `string`                           | Associated gene name (e.g., "IL6")     |
| `reason`   | `string`                           | Why this SNP is relevant to the query  |
| `evidence` | `"weak" \| "moderate" \| "strong"` | Evidence strength                      |
| `priority` | `number`                           | Priority order (1 = highest)           |

### SafetyInfo

| Field             | Type                          | Description                             |
| ----------------- | ----------------------------- | --------------------------------------- |
| `diagnosis`       | `boolean`                     | Whether query requests diagnosis        |
| `medicalAdvice`   | `boolean`                     | Whether query requests treatment advice |
| `disclaimerLevel` | `"low" \| "medium" \| "high"` | Required disclaimer level               |

### Example

```json
{
  "version": "1.0",
  "intent": "explore_gene",
  "topic": "inflammation",
  "snps": [
    {
      "rsid": "rs1800795",
      "gene": "IL6",
      "reason": "IL-6 promoter variant associated with inflammatory response",
      "evidence": "moderate",
      "priority": 1
    },
    {
      "rsid": "rs1205",
      "gene": "CRP",
      "reason": "CRP gene variant affecting baseline inflammation levels",
      "evidence": "strong",
      "priority": 2
    }
  ],
  "includeNotes": [],
  "safety": {
    "diagnosis": false,
    "medicalAdvice": false,
    "disclaimerLevel": "low"
  }
}
```

### Validation

QueryPlan is validated using Ajv against the JSON schema in `src/models/queryPlan.schema.json`. The validation function is in `src/utils/validateQueryPlan.ts`:

```typescript
import { validateQueryPlan } from './utils/validateQueryPlan'

const plan = validateQueryPlan(rawJson) // Throws if invalid
```

## MatchResult

The `MatchResult` maps requested SNPs to the user's actual genotypes from their local DNA index.

### Schema

```typescript
type MatchResult = {
  [rsid: string]: {
    genotype: string | null // e.g., "AT", "GG", or null if not found
    evidence: string // From the QueryPlan
  }
}
```

### Example

```json
{
  "rs1800795": {
    "genotype": "GC",
    "evidence": "moderate"
  },
  "rs1205": {
    "genotype": "CT",
    "evidence": "strong"
  },
  "rs123456": {
    "genotype": null,
    "evidence": "weak"
  }
}
```

### Generation

MatchResult is generated by `src/utils/match.ts`:

```typescript
import { matchQueryPlan } from './utils/match'

const result = matchQueryPlan(plan, snpIndex)
```

## InterpreterResponse

The `InterpreterResponse` is the output from the Interpreter LLM, containing the analysis and answer.

### Schema

| Field                     | Type                            | Description                                 |
| ------------------------- | ------------------------------- | ------------------------------------------- |
| `answer_markdown`         | `string`                        | Main answer in Markdown format              |
| `key_points`              | `string[]`                      | Bullet-point summary of key findings        |
| `uncertainty`             | `"low" \| "moderate" \| "high"` | Overall uncertainty level                   |
| `used_snps`               | `string[]`                      | List of rsIDs actually used in the analysis |
| `what_this_does_not_mean` | `string`                        | Clarification of limitations                |
| `follow_up_questions`     | `string[]`                      | Suggested follow-up questions               |

### Example

```json
{
  "answer_markdown": "## Inflammation Response\n\nBased on your genetic variants, you carry the **GC** genotype at rs1800795 in the IL6 gene. This variant is associated with...\n\n### Key Observations\n\n- The GC genotype suggests intermediate IL-6 production\n- Combined with your CRP variant, this may indicate...",
  "key_points": [
    "IL6 rs1800795 GC genotype detected",
    "Associated with moderate inflammatory response",
    "CRP variant suggests baseline inflammation levels"
  ],
  "uncertainty": "moderate",
  "used_snps": ["rs1800795", "rs1205"],
  "what_this_does_not_mean": "This analysis does not diagnose any inflammatory condition. Genetic variants are just one factor among many that influence inflammation. Lifestyle, diet, and other environmental factors play significant roles.",
  "follow_up_questions": [
    "Would you like to know about dietary factors that affect inflammation?",
    "Are you interested in other genes related to immune response?"
  ]
}
```

### Type Definition

Located in `src/models/interpreter.ts`:

```typescript
export interface InterpreterResponse {
  answer_markdown: string
  key_points: string[]
  uncertainty: 'low' | 'moderate' | 'high'
  used_snps: string[]
  what_this_does_not_mean: string
  follow_up_questions: string[]
}
```

## Preferences

User preferences stored in IndexedDB.

### Schema

| Field               | Type                                  | Default    | Description                                |
| ------------------- | ------------------------------------- | ---------- | ------------------------------------------ |
| `explanationLevel`  | `"layman" \| "normal" \| "technical"` | `"normal"` | Detail level of explanations               |
| `tone`              | `"calm" \| "formal"`                  | `"calm"`   | Response tone                              |
| `showUncertainty`   | `boolean`                             | `true`     | Show uncertainty indicators                |
| `language`          | `"sv" \| "en"`                        | `"sv"`     | Interface language                         |
| `autoSendGenotypes` | `boolean`                             | `false`    | Skip confirmation before sending genotypes |

### Example

```json
{
  "explanationLevel": "normal",
  "tone": "calm",
  "showUncertainty": true,
  "language": "sv",
  "autoSendGenotypes": false
}
```

## SNP Index Metadata

Metadata stored alongside the SNP index.

### Schema

| Field        | Type                                                   | Description              |
| ------------ | ------------------------------------------------------ | ------------------------ |
| `vendor`     | `"23andme" \| "ancestry" \| "myheritage" \| "unknown"` | Detected file vendor     |
| `fileName`   | `string`                                               | Original filename        |
| `count`      | `number`                                               | Number of SNPs parsed    |
| `hash`       | `string`                                               | SHA-256 hash of the file |
| `uploadDate` | `string`                                               | ISO 8601 timestamp       |

### Example

```json
{
  "vendor": "23andme",
  "fileName": "genome_data.txt",
  "count": 638421,
  "hash": "a1b2c3d4e5f6...",
  "uploadDate": "2024-12-22T10:30:00.000Z"
}
```
